Petunjuk Penggunaan Panel Maintenance
Selamat Datang di Panel Maintenance Desa Kalait Raya

Di panel ini, Anda dapat mengelola data kependudukan secara real-time yang langsung disinkronkan ke halaman utama website publik menggunakan penyimpanan browser (*localStorage*).

Cara Melakukan Pembaruan Data:
  1. Gunakan menu di samping kiri untuk membuka kategori data yang ingin diubah (Kependudukan, Pekerjaan, Perangkat, dll).
  2. Ubah informasi di kolom formulir yang tersedia.
  3. Klik tombol **Simpan Perubahan** di bagian bawah form tersebut.
  4. Buka/muat ulang Halaman Utama Publik untuk langsung melihat perubahannya.

Permanenkan Data di Source Code

Karena data di panel ini disimpan di *localStorage* browser pengunjung, perubahan tersebut hanya aktif di browser saat ini. Untuk memperbarui website secara permanen di server, salin data JSON berikut dan gantikan nilai variabel `DEFAULT_DATA` di file `js/script.js` proyek Anda.

Zona Bahaya

Gunakan tombol berikut jika Anda ingin menghapus seluruh data kustom yang telah Anda buat di browser saat ini dan mengembalikannya ke data default asli bawaan website.
